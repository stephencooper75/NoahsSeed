# Changelog

All notable changes to Noah's Seed will be documented in this file.

The project follows a milestone-based development approach.

---

## v0.1.3 – Activity Metadata

### Added

- Activity objects now include id, name and icon.
- Engine loads activities from `ACTIVITY_DATA`.
- Activity Registry now stores complete Activity objects rather than just IDs.

---

## v0.1.2 – Activity Registry

### Added

- Engine now owns and registers all Activity objects.
- Activities can be retrieved from the registry instead of being created on demand.

---

## v0.1.1 – Engine Foundation

### Added

- Introduced the Noah's Seed Engine (`engine.js`).
- Activity completion is now routed through the Engine.

---

## v0.1.0 – Working Prototype

### Added

- First playable bedtime routine.
- Four activity buttons.
- Progress tracking.
- Completion messages.

---

## v0.0.1 – Project Foundation

### Added

- Initial project structure.
- Documentation framework.
- Architectural foundations.
- Vision document.
- Coding standards.
- Project backlog.
- Project structure documentation.
- Git repository.
- GitHub repository.
- Development environment configuration.
