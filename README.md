# Noah's Seed

Noah's Seed is a living educational world designed to grow with children and families over many years.

The project combines learning, creativity, exploration and healthy habits within a safe, non-addictive environment.

## Vision

The project has two primary goals:

1. Create a world that encourages curiosity, kindness and lifelong learning.
2. Build a flexible engine that can adapt to different families, interests and stages of childhood.

## Development Principles

Noah's Seed is built around a small number of core principles:

- Build the engine, not just the game.
- Behaviour belongs in code.
- Content belongs in data.
- Design generic systems before specific content.
- Prefer long-term maintainability over short-term convenience.

## Repository Structure

- `app/` – Application source code and assets
- `content/` – Game content stored as data
- `docs/` – Project documentation
- `tools/` – Development utilities
- `archive/` – Retired experiments and prototypes
- `releases/` – Milestone snapshots
