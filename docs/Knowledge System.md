# Knowledge System

## Core Principle

Educational content adapts to demonstrated understanding, not simply age.

---

Each topic contains multiple explanation levels.

Example:

Topic: Gravity

Level 1
- Apples fall down.

Level 2
- Gravity pulls objects toward Earth.

Level 3
- Every object with mass attracts every other object.

Level 4
- Newton's Law of Gravitation.

Level 5
- Differential calculus models continuously changing motion.

Level 6
- Einstein explains gravity as spacetime curvature.

---

The game determines which explanation level is appropriate based on the player's demonstrated understanding, interests, and progress.

The same world event can therefore teach increasingly sophisticated ideas without changing the underlying game.
