# Decision Framework

Whenever a new feature is requested, answer these questions.

1.
What capability is really being requested?

2.
Can an existing capability support it?

3.
Should a new capability be created?

4.
What future features become possible?

5.
Does this strengthen Noah Engine?

6.
Does it belong in the engine or in content?

7.
Does it introduce unnecessary coupling?

If the answer to Question 7 is yes, redesign before coding.
