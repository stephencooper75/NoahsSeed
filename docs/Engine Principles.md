# Noah's Seed Engine Principles

## 1. Build permanent systems before temporary features.

## 2. The world determines what actions are available.

## 3. Objects expose interactions.

## 4. The simulation changes the world.

## 5. The renderer visualises the world.

## 6. Educational content adapts to demonstrated understanding, not simply age.

## 7. The game should inspire real-world curiosity and activities.

## 8. World objects should support continuous progression (e.g. growth values), with visual milestones chosen by the renderer.

## 9. Content should be data-driven wherever practical so new activities, recipes, experiments, and plants can be added without changing engine code.

## 10. Every new subsystem should represent a permanent concept in the world, not just an implementation detail.
