# Learning Profile System

## Purpose

Estimate the player's current understanding across many independent topics using evidence gathered naturally during gameplay.

## Principles

- Never diagnose.
- Never shame.
- Never block progress because of a wrong answer.
- Adapt quietly.
- Preserve curiosity.
- Allow every topic to progress independently.
- Use confidence estimates rather than fixed labels.
- Assessment should arise primarily from authentic gameplay rather than formal testing.

## Examples

Mathematics
- Addition
- Multiplication
- Fractions
- Algebra

Science
- Observation
- Cause and Effect
- Biology
- Chemistry
- Physics

Music
- Rhythm
- Melody
- Reading notation

Cooking
- Sequencing
- Measuring
- Kitchen safety

Gardening
- Plant care
- Life cycles
- Ecology

The engine updates confidence over time and uses it to choose appropriate explanations, activities, and challenges.
