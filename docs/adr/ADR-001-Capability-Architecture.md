# ADR-001

Title

Adopt Capability-Based Architecture

---

Status

Accepted

---

Decision

Noah Engine will be organised around reusable capabilities rather than individual features.

Examples

Instead of

"Piano"

the engine provides

"Music"

Instead of

"Ferris Wheel"

the engine provides

"Ride"

---

Reason

Capabilities maximise reuse.

New features strengthen the engine instead of increasing duplication.

---

Consequences

Future development must first identify the capability involved before implementing the feature.
